Workflow 01 / Textbook

            
教材 PDF，转成可编辑 MD

            
本机提取文字版 PDF 的章节、编号标题与原图，生成逐章 Markdown。扫描版不会伪造文字，会明确提示先用 MinerU 生成草稿。

          

        

        

          
          
          
          
          
        

        

          

            

              
1. 选择教材 PDF
仅本机解析，文件不会自动发往模型服务

            

            
            

            
    
              
  • 按「第 N 章」切分章节，忽略目录行
    • 
              
  • x.y / x.y.z 编号标题转为 Markdown 层级
    • 
              
  • 原图按页导出，题注下方插入引用
    • 
            

            

              
              
            

          

          

            

              
本机解析任务
刷新或重启后可从这里恢复查看
