# 图片页重排的通用风格流程

## 输入与职责

教师确认的大纲决定内容，原模板决定视觉风格。确定性工具提取主题色、字体、图片尺寸及部件证据。Qwen 从源页渲染图提取风格合同，DeepSeek 根据合同设计图片页，Qwen 再审查成品。各阶段均保留 API 原稿和可复核文件。

## 风格提取

读取源模板全部渲染页和 XML 配色证据。识别主色、辅色、强调色、正文、底色、衬底，记录可见来源。Office 默认主题色只作为证据之一。可以从主色派生浅色衬底，注明派生关系。低饱和模板保持原有气质。使用当前模板的字体和视觉母题。

## 执行器的设计任务

图片页从其源页的空白内容区域重新设计。每页先决定阅读顺序、主视觉和要点层级，再安排色块、文字和图片。主色用于建立明显的视觉重心，辅色用于分组，强调色用于核心结论或节点，中性色用于阅读和呼吸空间。根据模板合同选择实色标题区、浅色衬底、深色结论区、细分隔等组合，避免全套退化为白底灰卡片加一条细色线。

流程图页、代码解释页和多图比较页采用与内容相符的不同结构，并通过字体、色彩和间距保持同一风格。色块应承载标题、分组或结论，控制装饰密度。正文与底色保持可读对比。保留图片原始比例和全部信息，保证坐标轴、标签和代码均可见。装饰不能叠在教材图之上。位图本身不改色，文本和新增视觉元素保持原生可编辑。

颜色角色不是固定的文字与底色配对。深色区域采用浅色正文，浅色区域采用深色正文。正文和必要图注的文字对比度至少4.5:1，强调色不足以承载小字时，用它作衬底或边界并配深色文字。

执行器生成 style-decisions.json，逐页记录采用的颜色角色、阅读顺序、对比区域和图片安全区域，以及必要取舍。模板文字页继续采用源结构。所有事实、参数、作业仍来自指定大纲。

## 视觉验收与回流

将模板参考、上一轮成品与新成品交给 Qwen。逐页审查风格一致性、色彩层次、阅读顺序、配色协调、图片完整性和可读性，定位具体问题。视觉继承和美观度分别给出判断。纯粹“没有遮挡”不足以证明美观。

Qwen 输出的可操作问题和 DeepSeek 的内容漏项审查作为下一轮执行器输入。修复由 DeepSeek API 完成，代理仅启动流程、修复运行错误、渲染和记录。对任意新模板，先重新提取风格合同，禁止复用另一模板的颜色值。跨模板验证应检查风格合同的差异，也应明确哪些模板已实际生成并验收成品。
