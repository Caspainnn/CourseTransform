# 01 环境依赖与一键安装

## 1. 运行环境

| 项目 | 要求 | 说明 |
|---|---|---|
| 操作系统 | Windows 10 / 11（64 位） | PPT 预览/质检依赖桌面 PowerPoint COM，Linux 不支持 |
| Python | **3.11.x** | `requirements.lock.txt` 按 3.11 锁定 |
| Office | **桌面版 PowerPoint 2016+**，建议同时安装 Word | 逐页渲染、文字边界质检；WPS 不能替代 COM |
| 外部运行时 | PPT Master（`PPTMASTER_SKILL_DIR`）与 `PPTNATIVE_RUNTIME_HOST` | 独立分发，需自行获取；本仓库不随附 |
| 浏览器 | Chrome / Edge 近两年版本 | 前端为原生 JS，无构建步骤 |
| 可选 | MinerU 4.x（扫描版 PDF）、Node 20（历史 opencode 托管） | 不装 MinerU 时扫描件走 RapidOCR |

## 2. 一键安装（Windows PowerShell）

```powershell
powershell -ExecutionPolicy Bypass -File readme/scripts/install.ps1
```

脚本会：检查 Python 版本 → 创建 `.venv` → 安装锁定依赖 → 运行 `scripts/doctor.py` 自检 →
在缺少 `.env` 时从 `.env.example` 复制模板（不会写入任何密钥）。

手动安装等价于：

```powershell
py -3.11 -m venv .venv
.venv\Scripts\activate
pip install -r requirements.lock.txt
python scripts/doctor.py
```

## 3. 必填配置

复制 `.env.example` 为 `.env`（已被 `.gitignore` 排除），至少填写：

```ini
LLM_BASE_URL=https://your-openai-compatible/v1
LLM_API_KEY=...
LLM_MODEL=your-reasoning-model
LLM_OUTLINE_JSON_MODEL=your-vision-model
```

外部运行时（二选一：环境变量或 `local-config.json`）：

```json
{
  "PPTMASTER_SKILL_DIR": "D:\\Runtime\\ppt-master",
  "PPTNATIVE_RUNTIME_HOST": "D:////Runtime////host"
}
```

`scripts/doctor.py` 会只打印“是否存在”，不会输出任何密钥。

## 4. 常见问题

- `PowerPoint.Application` 为 false：安装桌面 Office 并用同一账号首次启动一次。
- 生成时提示找不到 `svg_to_pptx.py`：`PPTMASTER_SKILL_DIR` 指到了错误的目录。
- 预览中文变方块：安装中文字体（如思源黑体/微软雅黑）。
- 扫描版 PDF 报 OCR 错误：安装 MinerU，或设 `PDF_OCR_ENGINE=rapidocr`。
- Linux 服务器：解析/教案逻辑可跑，但 PPT 预览与质检不可用；不要用 Ubuntu 部署完整链路。
