# 02 部署与运行

## 1. 本地开发运行

```powershell
python run-local.py --port 7873
# http://127.0.0.1:7873/
```

首次使用：注册账号 → 左下角“用户信息”确认登录 → “模型管理”填写模型（或在 `.env` 配默认模型）。

## 2. 生产运行（单机 Windows）

推荐 **Windows 服务 + 反向代理**：

1. 用虚拟环境安装依赖，确认 `python scripts/doctor.py` 全部为 true。
2. 用 NSSM/WinSW 把 `run-local.py --port 7873` 注册为服务（开机自启、失败重启）。
3. 反向代理（Caddy/Nginx）监听 443，转发到 `127.0.0.1:7873`；配置 HTTPS 证书。
4. 安全组/防火墙只放行 443（及受限的 22/3389），**不要**把 7873 直接暴露公网。
5. 环境变量：`AUTH_SECRET` 固定、`AUTH_COOKIE_SECURE=1`（HTTPS 时）。

> 用 `IP:端口` 直接测试时不具备 HTTPS，登录密码会明文传输；仅限临时验收，正式使用必须有 HTTPS。

## 3. 账号、数据与备份

- 数据根：`data/`；每个账号：`data/users/<uid>/{tasks,files,knowledge,pipeline}`。
- 账号：`data/users.json`（PBKDF2 加盐哈希，无明文密码）。
- 模型配置：`data/users/<uid>/models.json`（API Key 只在本账号目录）。
- 备份：定期打包 `data/`（含用户任务、知识库、模板、产物）；保留 7–30 天。
- 升级：停服务 → 备份 `data/` → 更新代码 → `pip install -r requirements.lock.txt` → 启动 →
  健康检查 `/api/health` → 登录跑一条最小链路。

## 4. 运行约束

- PPT 逐页预览、文字边界质检、原生导出依赖 **桌面 PowerPoint**；这是项目的明确约束，不做跨平台承诺。
- 生成任务串行执行（PowerPoint 单实例），并发请求会排队；建议单机部署。
- 模型网关需从部署机可访问；校内网关通常有网络限制，公网部署请改用可访问的 OpenAI 兼容服务。

## 5. 快速验收清单

1. `GET /api/health` 返回 `modelConfigured=true`、`nativeRuntime=true`。
2. 注册/登录/退出正常，换账号看不到他人任务。
3. 上传 `examples/demo_textbook.pdf` → 解析 → 下载 ZIP。
4. 上传 `examples/textbook_demo.md` → 生成教案 → 下载 DOCX。
5. 建 PPT 任务 → 生成 → 预览 → 单页修改 → 确认下载。
