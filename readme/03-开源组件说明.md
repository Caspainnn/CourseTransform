## 外部运行时与商业组件

- **PPT Master**：独立分发的完整原版发行包，需自行获取并设置 `PPTMASTER_SKILL_DIR`；
  其许可证与 attribution guard 独立生效，本仓库不授予其任何权利，也不修改其脚本。
- **Microsoft PowerPoint / Word**：需有效商业授权；预览与质检依赖其 COM 接口。
- **字体**（微软雅黑、思源黑体等）：随系统或单独授权，仓库不再分发字体文件。
- 历史 OpenCode 托管为可选外部组件，不参与当前生产链路。
